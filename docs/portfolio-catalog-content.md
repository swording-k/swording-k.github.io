# 作品册分类与内容维护

原始项目文章仍是单一内容源。文章的 `data-book-category` 决定目录分组，书页按分类稳定排序，原始列表不重排。

介绍规则（2026-10-29 起）：第一段先讲产品——它是什么、解决什么问题、哪一点值得试，控制在 90 字以内（优先 50–80 字）；完全属于本人的项目不写“我做了某某”，也不使用“全链路由我完成”一类自述。开源/协作项目可在展开段落用一两句说明担任的角色。展开介绍只保留产品细节与体验方式，不写职责清单。

分类为个人产品、开源贡献、黑客松作品、工具与内容。新增作品时，沿用原文章结构并填写分类即可加入；未知分类暂归工具与内容。Mine Radio 暂不公开加入，待所有者确认后处理，不据开发进展推断 App Store 上架。
