# 长爪简介文案更新设计

## 目标

将首页三剑陈列中“长爪”的介绍重点调整为其材质与持有者：明确它是《权力的游戏》中琼恩·雪诺使用的瓦利利亚钢佩剑，不再提及莫尔蒙家族，同时保留原有文学描述。

## 最终文案

> 《权力的游戏》中琼恩·雪诺使用的瓦利利亚钢佩剑。冷灰钢与旧皮革，一把经历过风霜的守誓之剑。

## 修改范围

- 更新 `index.html` 中首屏默认展示的长爪简介。
- 更新 `js/weapon-armory-data.mjs` 中切换武器时读取的长爪简介。
- 更新自动化测试，要求长爪简介包含“瓦利利亚钢”，且不包含“莫尔蒙家族”。
- 不修改另外两把剑的名称、介绍、图片或交互效果。

## 验收标准

1. 首次打开首页时，长爪简介显示最终文案。
2. 切换到其他宝剑再切回长爪后，仍显示同一份最终文案。
3. 项目现有测试及新增文案断言全部通过。
