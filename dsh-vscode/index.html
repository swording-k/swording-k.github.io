DeepSeek Harness for VS Code

在编辑器里直接用 DeepSeek Harness：左侧启动器列出当前项目的对话，一点就在编辑器右侧打开完整界面，自动对齐你的工作区。

版本 0.6.0 协议 MIT 要求 VS Code ≥ 1.94 非官方社区扩展
⬇ 下载扩展（.vsix） 查看源码 →

它能做什么

把 DeepSeek Harness 放进 VS Code，而不是让你在浏览器和编辑器之间来回切。

🗂 侧边栏启动器

显示当前文件夹的对话列表，一键新建或继续。

➡️ 对话开在右侧

点开即用，和你的代码并排，左边看文件右边聊。

🎯 自动对齐工作区

打开哪个项目，对话就绑定哪个目录，agent 读写的是同一批文件。

🧭 四个入口

活动栏、右侧栏、编辑器右上角、状态栏都能进。

🌗 主题跟随

自动同步 VS Code 深浅色，不用手动调。

⚙️ 服务自动启动

检测到 dsh 没跑就自动拉起，不用先开终端。

安装 · 三步

全程约 3 分钟。前提：Node.js ≥ 22、已安装或即将安装 DeepSeek Harness。

  1. 安装 DeepSeek Harness打开终端运行下面这条，会装 600 多个依赖包，耐心等 1–3 分钟。 
    npm install -g @deepseek-ai/dsh
    装完用 dsh --version 验证。
  2. 安装本扩展去 Releases 下载 dsh-vscode-0.6.0.vsix， 然后在 VS Code 按 Cmd+Shift+P， 输入 Install from VSIX → 选中下载的文件。 装完执行一次 Developer: Reload Window 让扩展生效。
  3. 打开你的项目，点鲸鱼图标左侧活动栏会出现 DeepSeek Harness 图标。点它 → 看到当前文件夹 → 点"＋ 新建对话"。 完整界面会在编辑器右侧打开，直接可以对话。

配置 API

扩展本身不需要密钥，密钥是 DeepSeek Harness 用的。

方式一（推荐）：第一次打开界面时，进 设置 → 账户 / Account，填入你的 API Key，界面会记住。
方式二：在终端里设置环境变量，再重启 VS Code： 
export DEEPSEEK_API_KEY=sk-你的密钥

设置项

VS Code 设置里搜 dshHarness 就能找到。

设置默认说明
dshHarness.repoPath空可选：指向一份 deepseek-harness 源码目录（留空则用 PATH 里的 dsh）
dshHarness.commanddsh启动服务的可执行文件
dshHarness.port3080本地服务端口
dshHarness.autoStarttrue服务没跑时自动启动
dshHarness.syncThemetrue让界面跟随 VS Code 深浅色

常见问题

提示找不到 dsh？

说明还没装或不在 PATH。重跑第 1 步，或把 dshHarness.repoPath 指向你的源码目录。

端口被占用？

把 dshHarness.port 改成别的，比如 3081。

图标找不到？

命令面板执行 View: Reset View Locations，再重载窗口。

打开后没落到对应对话？

官方 npm 版 dsh 缺少会话定位支持；扩展会自动装配套插件，重载界面即可。
